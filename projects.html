An AI workflow that can pick up where it left off.

A local-first AI desktop application built with FastAPI, WebSockets, React, TypeScript, Tauri, and SQLite. The engineering focus: recover interrupted work reliably and keep external actions tied to explicit approval.

React + Tauri↔FastAPI + agents↔SQLite
Recover without repeating
Restores saved responses and resumes eligible interrupted agent runs under their original IDs. Idempotent processing prevents duplicate messages and external actions.
Keep approvals meaningful
Centralized approval validation binds external actions to verified recipients and reviewed message content. Enrichment requests and API entry points preserve authorization.
Test the failure paths
228 pytest and 35 Vitest tests for the Gmail connection feature cover migrations, retries, message attribution, and failure recovery.
