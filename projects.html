Sourcecado

  • React

Keeping contacts, conversations, and tasks connected.

Sourcecado is a local-first AI application for managing sponsor contacts. I developed shared CRM features across chats, integrated Gmail synchronization, and built recovery safeguards so interrupted workflows can resume with clear boundaries around external actions.

React interface→FastAPI + CRM→SQLite
Shared task management across chats
Built shared tasks with descriptions, due dates, AI suggestions, and urgency labels, keeping contact-related work accessible across conversations rather than isolated in a single chat.
Gmail synchronization that preserves progress
Implemented persistent checkpoints, message deduplication, and contact matching. Synchronization can recover its progress after failures while preserving conversation history and avoiding duplicate messages.
Recovery that accounts for uncertain outcomes
Used saved checkpoints and execution records to distinguish work that is safe to resume from external actions whose outcomes are unknown. Those uncertain actions require review before retrying.

Doodle2Design

  • Python
  • JavaScript
  • FastAPI
  • OpenAI API
  • pytest

Turning a rough sketch into a website redesign.

A full-stack application that translates sketches, uploaded images, and visual preferences into redesigned web pages. I built the application and integrated OpenAI models for image analysis and page generation. The project placed second in a hackathon hosted by Amazon and Google employees.

Hackathon finish
2nd place

Sketches + images→OpenAI analysis→Redesigned pages
A complete path from visual input to generated pages
Built the full-stack workflow around user sketches, uploaded images, and visual preferences, connecting those inputs to image analysis and website generation through the OpenAI API.
Generation guided by 30 design templates
Compared user inputs with a collection of 30 design templates to guide the generated layout, style, and visual consistency, giving the redesign process a concrete set of references.
A mood dataset based on agreement across models
Created a dataset of 50 images with mood labels generated by models from OpenAI, Anthropic, and Google. Retained the labels identified by all three models rather than relying on a single model's interpretation.

03

Full-stack web · Student utility

Campus Event Finder

  • Python
  • Flask
  • SQLite
  • HTML/CSS
  • pytest

Making campus events easier to find and manage.

A full-stack web application for students to discover events by date, category, and campus location. I built the event search experience and a Flask REST API backed by SQLite, with authentication and input validation around account access and event submissions.

Student interface→Flask REST API→SQLite
Search around a student's plans
Built search and filtering by date, category, and campus location so students can narrow the event list to activities that fit their schedule and interests.
A REST API with persistent event storage
Designed Flask endpoints for creating, retrieving, filtering, and deleting events. Used SQLite to store event data persistently and support the application's event-management workflow.
Account protection and validated submissions
Integrated user authentication to protect accounts and input validation to prevent invalid event submissions, handling both access and data quality at the application boundary.
