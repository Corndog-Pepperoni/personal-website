# Technology marks

These monochrome marks are bundled locally and inherit the site's blue/pink palette. They identify the technologies in Conor's toolkit, without suggesting endorsement.

- Python, C, TypeScript, HTML5, CSS, React, FastAPI, Flask, Tauri, SQLite, Git, GitHub, Docker, pytest, Vitest, Selenium, and Model Context Protocol: [Simple Icons 16.35.0](https://github.com/simple-icons/simple-icons/releases/tag/16.35.0). Distributed under the included CC0 license.
- Java and Visual Studio Code: [Devicon 2.17.0](https://github.com/devicons/devicon/releases/tag/v2.17.0), with its included MIT license.
- SQL, REST APIs, WebSockets, and VADER: original illustrative symbols for the database language, API style, communication protocol, and sentiment-analysis tool. These are not presented as official brand logos.

Brand SVG paths are retained; fills are normalized to `currentColor` for consistency with the requested palette. HTML/CSS displays both technology marks. Text labels remain visible for every item; graphics are decorative for assistive technology.
